# Лабораторная работа №1. Web-технологии.

**Студент:** Ярослав Бормотов  
**Вариант:** 7 — «Эко-активист»  
**Тема:** Страница «О себе» с зелёно-белой цветовой гаммой.

## Цель работы
Освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, изображениями и формами.

## Что реализовано
- `<header>` — шапка с именем и заголовком страницы.
- `<main>` — основной контент.
- Две секции `<section>`:
  - «Навыки» — маркированный список `<ul>`.
  - «Проекты» — нумерованный список `<ol>` из 4 пунктов.
- `<aside>` — боковая панель с любимым эко-принципом (Zero Waste).
- `<footer>` — подвал с копирайтом и годом.
- Изображение `52.jpg` с атрибутами `src`, `alt`, `width`, `height`.
- Форма обратной связи: поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`), кнопка отправки. У всех полей есть `name` и `placeholder`.
- Цветовая гамма: зелёно-белая.
